Costa Solara is a 2D top-down open-world game set in a sun-soaked coastal city. Drive and walk the streets, steal cars, dodge traffic and pedestrians, outrun the police as your wanted level rises, and run six courier missions as Mara Voss of the Solara Swift crew.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the whole game is static files under `game/`.

## Controls

- **WASD / arrow keys** — walk and drive
- **E** — enter / exit a car
- **F** — punch
- **Enter** — start / confirm
- **P** — pause, **M** — mute
